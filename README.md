# XC60 Car Video

Android Automotive OS parked-video proof-of-concept for a Volvo XC60 with Google built-in.

- Opens the mobile YouTube website inside an in-app WebView.
- Declared as an AAOS `video` app.
- Not marked `distractionOptimized`, so the vehicle can block it while driving.
- Intended for internal testing / parked use.
- No CAN bus, speed, GPS, microphone, contacts, or vehicle-data access.

Build outputs are produced by GitHub Actions.
